# TerraSphere

A relaxing 3D terrarium simulator built solo for StormHacks 2026.

Inspired by self-sustaining terrariums, TerraSphere lets you create a small habitat and watch plants, ants, and isopods interact.

## Features

- Ants explore, harvest food, and carry it back to their nest.
- Isopods consume leftover food scraps.
- Plants produce food for the terrarium.
- A soil-moisture system tracks enclosure conditions.
- Place bugs, plants, and food.
- Pause or speed up the simulation.
- Save and load your progress.

## Built With

- Godot 4
- GDScript
- Publicly available 3D models, textures, and audio
- Codex for coding and debugging assistance

## Running the Project

1. Clone or download this repository.
2. Open Godot and import `project.godot`.
3. Allow assets to finish importing.
4. Press F5 to run the project.
